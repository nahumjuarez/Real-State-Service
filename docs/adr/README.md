# Architecture Decision Records (ADR)

Los ADR documentan decisiones que sería costoso olvidar o revertir.

Formato recomendado:

```markdown
# ADR-XXX — Título

## Estado
Propuesto | Aceptado | Reemplazado

## Contexto

## Decisión

## Alternativas consideradas

## Consecuencias
```
